# Método — como cada item sai completo

O objetivo é que cada lead / concorrente / achado saia **pronto para agir**: a pessoa confere na tela
e age, sem precisar pesquisar de novo. Pesquise com busca na web, mapas e perfis públicos. Nunca
invente dado — quando não achar, escreva "N/A".

## Padrão de LEAD (objetivo = achar clientes)

| Campo | Como preencher |
|---|---|
| **Negócio** | Nome como aparece. |
| **Nicho** | Segmento (barbearia, estética, restaurante...). |
| **Região** | Bairro / cidade. |
| **Endereço** | Rua + número se houver; senão bairro. |
| **Instagram / site** | @ e/ou URL. |
| **Funcionando?** | Confirme no Google/Maps (nome + bairro + horário). Aberto com sinais recentes → "✅ Aberto (confirmado)". Sem certeza → "⚠️ Conferir". Fechado permanentemente → "❌ Fechou" (não procurar). Fonte no campo Fontes. |
| **Google Maps** | `https://www.google.com/maps/search/?api=1&query=<nome+endereço codificado>` |
| **Contato** | WhatsApp / telefone da bio, site ou Google. "N/A" se não achar. |
| **Dono / responsável** | Nome se aparecer em bio/site/post. Senão "N/A". |
| **Métricas** (se tiver acesso) | Seguidores, posts no mês, último post, engajamento aparente. |
| **Gancho de abordagem** | 1 observação **real e específica** de um post/página (não genérico). Serve de ponte pra conversa. |
| **Próximo passo sugerido** | Ex: "comentar em 1–2 posts, depois DM no dia seguinte". Sugestão — a pessoa decide. |
| **Fontes** | Links de onde cada dado saiu. |

## Padrão de CONCORRENTE (objetivo = mapear concorrência)

- Nome, região, canais (Instagram/site/Maps).
- Posicionamento (como se vende: premium, barato, rápido...).
- Preço aparente, se público.
- Pontos fortes e fracos observáveis.
- Fonte.

## Padrão de MERCADO (objetivo = entender um mercado)

Relatório em seções: tamanho/estimativa, principais players, faixas de preço, tendências recentes,
lacunas/oportunidades. Cada afirmação com fonte.

## Tom dos rascunhos de abordagem (quando a pessoa pedir)

- Primeira pessoa, natural, curto, pouco emoji.
- O gancho tem que bater com algo real e recente (imagem, data, legenda). Não comente evento que já
  passou como se fosse futuro.
- Sem promessa de resultado, sem preço, sem "chama no direct". É conversa, não anúncio.
- São **sugestões**. Quem envia é a pessoa, depois de conferir.

## Proibido

Agir pela pessoa nas redes (seguir, curtir, comentar, enviar DM). A skill só pesquisa e sugere.
